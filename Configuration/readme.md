Tuning tips:

Using our base Orca Slicer configuration print a simple 30mm cube

We need to calculate our shrinkage.

(it is important to do this with different filaments and filament brands)

set shrink to 100 for XY and Z

Print the cube.

first maths is simple. 

PHYSICAL MEASURMENT / 30 * 100 = new shrinkrate

Re slice and re-print using your new shrink settings.

To caclulate further use this:

New Shrink Rate (%) = (Desired Size / Measured Size) × Current Shrink Rate

Example:

New Shrink Rate = (30 / 29.85) x 101.03 = 1.00502 * 101.03 = 101.55%
